# SiteQuant Codex Instructions

## Project skills

- `sitequant-development`: Use for Flutter/Dart development, construction-calculation changes, UI work, debugging, AdMob/Firebase, Android/Play Store configuration, testing, and GitHub changes. Skill file: `.agents/skills/sitequant-development/SKILL.md`

## Repository rules

- Inspect the existing implementation before changing code.
- Prefer minimal, focused changes.
- Treat calculation formulas and engineering assumptions as production behavior.
- Preserve working AdMob/Firebase and platform configuration unless the requested change requires otherwise.
- Run appropriate validation after changes and report exactly what was verified.
- Do not merge, publish, force-push, or rewrite history unless explicitly requested.
